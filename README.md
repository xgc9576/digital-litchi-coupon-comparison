积分回馈比例低。100 元换 100 分，会员日 120 分，单日赠送上限 200 分。能换什么还要看积分商店当期上架了什么，没有固定的兑换比例，别把积分当成现金算。

售后有时间限制。客服在线时间是 9:30 到 21:30，晚上装不上只能等第二天。

授权由代理商提供，不是厂商直营，这一点页面自己写明了。介意授权链路的人，可以直接去厂商官网买原价，多花的钱买的是直营。
